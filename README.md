# Личный бюджет

Личный планер бюджета. Работает в браузере телефона без интернета и без аккаунтов.
Данные хранятся только на устройстве.

Адрес приложения (GitHub Pages): https://remiz2000-collab.github.io/money-big/

## Установка на телефон
- iPhone (Safari): «Поделиться» → «На экран "Домой"».
- Android (Chrome): меню ⋮ → «Установить приложение».

## Для разработки
- `src/` — исходники (логика, интерфейс, стили).
- `node build.js` — собирает `index.html` из `src/`.
- `node test/test.js` — проверки финансовой логики.
- При каждом обновлении поднимайте `VERSION` в `sw.js`, чтобы телефон скачал новую версию.
